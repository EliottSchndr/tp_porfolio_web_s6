## Installation et lancement

Pour lancer le projet en local, suivez ces étapes.

### Prérequis

*   [Node.js](https://nodejs.org/) (version 18.x ou supérieure)
*   [npm](https://www.npmjs.com/) (généralement inclus avec Node.js)

### Étapes

1.  **Clonez le repository :**

    ```bash
    git clone https://github.com/EliottSchndr/tp_porfolio_web_s6
    cd tp_porfolio_web_s6
    ```

2.  **Installez les dépendances :**

    On utilise npm pour gérer nos packages. Lancez la commande suivante à la racine du projet pour installer tout ce qu'il faut :

    ```bash
    npm install
    ```

3.  **Lancez le serveur de développement :**

    Une fois les dépendances installées, vous pouvez lancer le serveur de développement avec Vite.

    ```bash
    npm run dev
    ```

    Normalement, le site devrait être accessible sur [http://localhost:5173](http://localhost:5173).
